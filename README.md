# KasPOS

### Kasir Pintar, Bisnis Lancar. Tanpa Kuota Internet.

KasPOS adalah aplikasi kasir sederhana untuk membantu UMKM mengelola transaksi dan operasional toko langsung dari smartphone.

**Kelola Tokomu Layaknya Minimarket Modern, Cukup dari Smartphone.**


## ✨ Fitur

* 🧾 Pencatatan transaksi penjualan
* 📦 Pengelolaan data produk
* 🔎 Pencarian produk dengan cepat
* 📷 Pemindaian barcode menggunakan kamera HP
* 📡 Dukungan barcode scanner Bluetooth
* 🔌 Dukungan barcode scanner melalui USB OTG
* 🖨️ Dukungan printer thermal Bluetooth
* 📊 Riwayat transaksi
* 📈 Pemantauan laba kotor
* 📥 Import dan export katalog produk
* 💾 Backup dan restore data transaksi
* 📒 Buku Kas Usaha
* 💰 Pencatatan pemasukan dan pengeluaran usaha
* ⏸️ Transaksi Sementara — simpan transaksi untuk dibukukan kemudian
* 📱 Operasional offline tanpa bergantung pada kuota internet

## 🤝 Coba Dulu

Silakan coba KasPOS terlebih dahulu untuk kegiatan usaha Anda.

Jika sesuai dengan kebutuhan dan membantu operasional toko, Anda dapat melanjutkan penggunaan dengan memberikan **donasi dukungan pengembangan**.

Belum sesuai dengan kebutuhan? Tidak masalah.

Masukan dan pengalaman pengguna akan menjadi bahan untuk terus memperbaiki kekurangan dan mengembangkan KasPOS agar semakin sesuai dengan kebutuhan usaha.
